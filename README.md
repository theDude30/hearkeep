# Hear & Keep

The website for **Hear & Keep: Sermon Notes**, an app for iPhone, iPad and Apple Watch:
https://thedude30.github.io/hearkeep/

- `index.html`: home
- `privacy/`: privacy policy (the App Store's Privacy Policy URL)
- `support/`: help and contact (the App Store's Support URL)

Plain HTML and one stylesheet. No scripts, cookies, web fonts or analytics. Served by GitHub
Pages from `main`.
